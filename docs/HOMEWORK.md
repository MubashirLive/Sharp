HOMEWORK
This file we are creating for the flow of homework module in our app.


Communication of the homework 
It will be done through the Messenger feature it's automatic messages and the broadcast messages this two features will be used and message checkbox will be used of student and the particular teacher who is assigning the homework.

Permission to assign the homework 
For teacher his allotted class -> section -> subject 
For class teacher - All the Subjects of his Class-section
Coordinator can give the homework in all the classes section subject under his wing.

Feature availability 
Available on both web and Android. 

Flow for assigning Homework 
1. Select Class -> Section -> Subject
2. Enter the title of the Homework - (Chapter Name - Place Holder)
3. Description.(Write Question 1 to 3 in your fair Notebook - Place Holder)
4. Button to Assign Now. or Schedule later. 
5. Top Right shows the todays date.
6. Clicking on the Assign Now assign it immediately and it will start refelecting in the calendar and send through the messenger.


FAQ
We have limited it to homework assignment - no checking, no submission system, only the track record when the Homework is assigned through the calendar feature. All other things are for next update not the part of MVP.
